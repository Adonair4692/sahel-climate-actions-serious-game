6. Verify Common Water Reserve: 18.

8. Verify five colour Hidden Zones and one Secret Mission zone per actor.
9. Verify Progress canonical order and six AGRHYMET seasonal mini-decks.
10. Verify Intervention deck and empty Visible/Covered Discard zones.
11. Install/confirm Guided Turn Manager v0.4 if using the tutorial.
