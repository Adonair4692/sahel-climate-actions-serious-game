# Guided Turn Manager - v2.5 package

Included script: `turn-manager-v0.4.lua`.

## Install

`Scripting -> Global -> Lua` -> replace Global Lua -> Save & Play.

## Current candidate features

- Card setup tutorial.
- Initial Preparation.
- Y1=0 / Y2=1 / Y3=2 / Y4=3 AGRHYMET/CILSS pairs per season.
- One complete GOV-to-PAS cycle per active pair; Year 1 ordinary cycle retained.
- Season Opening includes reset seasonal benefits before Water generation.
- Intervention hand-management tutorial.
- FULL / COMPACT / HIDDEN; TOP / BOTTOM; HIGH / DIM; Tutorial On/Off; Show Guide; Back; Next; Reset.
- Save/Load persistence with schema migration from older versions.

Candidate for human playtest. Full Y1-Y4 plus Final Resolution live ladder remains required before `v1.0`.
